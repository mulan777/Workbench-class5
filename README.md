# 中5班数字化倾听工作台 (Workbench-class5)

> 🏫 **中5班** 数字化倾听与班级日志工作台平台。
>
> 融合「班级日志·一周一页」视觉世界观与儿童自主交互心智，支持儿童自主选区、儿童自主拍照记录、想念与重逢时光墙、好朋友社交图谱及教师全维研判。

---

## 🌟 系统核心功能与架构特性

### 1. 班级日志世界观（视觉与交互）
- **日志纸面美学**：温暖米白纸面底色（`#faf6ee`）、格线肌理、朱砂印章盖印动效（`StampDone` / `stamp-seal`）与儿童原话手写字体。
- **糖果色胶囊系统**：基于标准 HSL 通道色彩变量（`--candy-pink`, `--candy-blue`, `--candy-green`, `--candy-yellow`, `--candy-purple`），为全班 25 位幼儿与活动区域赋予柔和、高辨识度的视觉锚点。
- **全站深浅色自适应**：支持 Light / Dark 双主题，380ms 柔和过渡，图表与界面元素自动适配。

---

### 2. 独立儿童自主端（免登录 · 零学习成本）

#### ① 儿童自主选区大屏 (`/select` 或 `/kiosk`)
- **零门槛双模式交互**：
  - **拖拽模式**：孩子长按自己的大号头像，直接拖入心仪的活动区域卡片放置槽。
  - **点击模式**：点击头像（高亮放大带呼吸外发光）➔ 点击目标区域，大屏触控秒级完成选区。
- **手机/移动端智能折叠**：竖屏设备上选中头像后，头像栏自动平滑折叠，核心选区区域上移至第一焦点；支持随时点击顶部胶囊展开换人。
- **即时正向激励**：内置 Web Audio API 清脆鼓励和弦音效，落位伴随朱砂盖章动画。
- **实时看板同步**：无需登录，后台多路原子操作保证“一人一天一区”，教师端看板 5 秒级静默自动刷新。

#### ② 儿童自主拍照上传台 (`/photo` 或 `/camera`)
- **直调硬件摄像头**：原生支持平板/手机摄像头权限（`capture="environment"`）与本地相册极速选图。
- **儿童自主上传流**：
  - 步骤一：点击选中自己的头像；
  - 步骤二：点击开启拍照取景或从相册选择；
  - 步骤三：预览确认后一键【发送到「想念与重逢」】。
- **历史时光回显**：选中小朋友后同步横向滚动陈列其历史照片足迹。

---

### 3. 教师研判与主题墙板块

#### ① 想念·重逢（第一、二周） (`/theme1`)
- **儿童照片实时回传**：自动承接儿童自主拍照台上传的照片与留言。
- **幼儿个案精准追踪**：
  - 支持下拉选择特定幼儿，一键过滤呈现该孩子的专属时光脉络与素材列表；
  - 顶部清晰显示每位幼儿当前上传素材计数。
- **教师板块全权归类**：教师可对每张照片快捷下拉归入**「旧时光留存」**、**「想念表达」**或**「重逢瞬间」**，并支持二次编辑描述与幼儿原话。

#### ② 区域选区大盘 (`/area`)
- **全班区域分布透视**：直观展示美工区、建构区、角色区、科学区、益智区、生活区、美发店等各区域入驻儿童头像矩阵与人数占比。
- **未选区儿童关怀卡**：自动识别并罗列当日尚未选区的在册幼儿。
- **伙伴交往深度统计**：基于同区自主游戏记录，沉淀全班 Top 8 伙伴结伴排行榜与儿童社交网络广度。
- **区域动态管理**：支持自定义新增区域、修改区域名称与 Emoji 图标、排序及安全防删校验。

#### ③ 每日签到台 (`/checkin`)
- **每日结伴签到**：记录幼儿每日入园结伴配对情况，支持照片上传与入园备注。
- **模拟演练与一键清理**：支持生成最近 N 周模拟数据供教学演示，并支持安全隔离清除。

#### ④ 数据总览大盘 (`/`)
- **五联满格日志卡**：今日签到、今日选区进度（实时出勤率）、想念素材、好朋友故事、热点问题。
- **高频结伴榜图表**：集成 Grok2API 现代图表观感（渐变填充面积、半透明圆角柱、彩色 Tooltip），完整呈现 Top 10 社交关系组合。
- **双瀑布流速览**：今日选区动态卡 + 最新想念与重逢相册胶卷。

#### ⑤ 用户与名册管理 (`/users`)
- **在册幼儿管理**：支持 25 位幼儿学号、姓名维护，**支持上传真实生活照/登记照头像**（未上传自动兜底糖果色首字头像），支持安全软停用与历史回溯。
- **教师权限体系**：支持管理员与普通教师账号创建、密码重置与权限控制。

## 🛠️ 技术栈与工程拓扑

### 前端 (`web-react/`)
- **核心框架**：React 18 + TypeScript + Vite 6
- **样式与设计系统**：TailwindCSS 4 + 自维护 Radix UI (Dialog / Tabs / Select / Tooltip / Dropdown)
- **图表与可视化**：Recharts (定制渐变柱状与社交分析图表)
- **图标与动效**：Lucide React + CSS Keyframe 印章盖落/纸页翻转动画

### 后端 (`server/`)
- **服务引擎**：Fastify 5 (高性能异步 Node 运行时)
- **数据库**：SQLite 3 (通过 `better-sqlite3` 高性能同步驱动)
- **鉴权与存储**：`@fastify/jwt` + `@fastify/cookie` + `@fastify/multipart` (静态上传至 `/uploads/`)

## 🚀 本地开发与启动指南

### 1. 环境准备
- Node.js >= 18.0.0
- npm >= 9.0.0

### 2. 启动后端
```bash
cd server
npm install
node src/index.js
# 后端将监听 http://127.0.0.1:3100
```

### 3. 启动前端
```bash
cd web-react
npm install
npm run dev
# 前端开发服务启动于 http://localhost:5173，自动代理 API 请求至 3100
```

## 🔒 安全与数据隔离说明
- 本仓库已配置严格的 `.gitignore` 规则，**完全剔除了本地真实 SQLite 数据库文件（`workbench.db`）与幼儿上传的真实照片数据（`uploads/`）**。
- 生产部署首次运行将依据 `schema.sql` 自动生成干净的初始库结构与默认活动区域。
